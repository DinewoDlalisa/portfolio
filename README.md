# Dinewo Dlalisa Portfolio

Personal portfolio website for Dinewo Dlalisa, UX/UI and graphic designer.

Hosted with GitHub Pages at https://dinewodlalisa.com

## Files
- `index.html` – the whole site (styles and scripts included)
- `photo.jpg` – portrait used in the opening section
- `logo.png` – logo (white, transparent background)
- `favicon.png`, `apple-touch-icon.png` – browser and phone icons
- `og-image.jpg` – preview image shown when the link is shared
- `CNAME` – tells GitHub Pages to use the custom domain
